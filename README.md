# Glass Convert

Фоновое приложение для Windows: зажмите **Shift** во время перетаскивания файла — рядом с курсором раскроется радиальное меню в стиле **liquid glass**. Отпустите файл на нужный формат, и готовая копия появится рядом с исходником.

```
┌───────────────────────────────────────────────┐
│   MP3      M4A      WAV                       │
│        ╭─────────────╮                        │
│   GIF  │ Shift + drag │  MP4                   │
│        ╰─────────────╯                        │
│   WEBM     PNG      ...                       │
└───────────────────────────────────────────────┘
```

## Что умеет

- Живёт в трее, не мешает работе и не показывает окон.
- Матовое стекло с настоящим размытием фона: меню показывает размытый десктоп под собой, снаружи фон остаётся резким.
- Глобально ловит **Shift + перетаскивание** (в Проводнике, на рабочем столе и т.д.).
- Радиальное меню под курсором: типы форматов зависят от того, что вы тащите.
- Конвертирует через встроенный `ffmpeg` (ничего устанавливать не нужно).
- Показывает прогресс в стеклянном тосте, по завершении — уведомление Windows.
- Результат кладёт **рядом с исходным файлом**, не перезаписывая существующие.
- Поддерживает перетаскивание сразу нескольких файлов.

### Форматы

| Исходник | Куда можно конвертировать |
| --- | --- |
| Аудио (wav, flac, ogg, m4a, aac, opus, wma…) | MP3, WAV, FLAC, OGG, M4A |
| Видео (mp4, mkv, mov, avi, webm, wmv…) | MP3, M4A, MP4, WebM, GIF, WAV |
| Изображения (png, jpg, webp, bmp, tiff, heic…) | PNG, JPG, WEBP, GIF, BMP |

## Запуск

Нужен [Node.js](https://nodejs.org) 18+.

```bash
npm install
npm start
```

При первом запуске скачивается Electron, дальше — мгновенно. Приложение не показывает главное окно: ищите иконку в системном трее.

## Как пользоваться

1. Возьмите файл в Проводнике и начните перетаскивать.
2. Не отпуская кнопку мыши, зажмите **Shift**.
3. Рядом с курсором появится радиальное меню. Ведите файл к нужному формату — подсветится кольцо и подсказка.
4. Отпустите файл. Тост покажет прогресс, готовый файл появится рядом с исходным.

> Меню открывается с короткой задержкой (~0,2 с): в этот момент делается снимок фона, чтобы стекло было по-настоящему матовым.

Дополнительно:

- **Ctrl + Alt + Space** или клик по иконке в трее — открыть меню вручную (потом можно перетащить в него файл).
- **Esc** — закрыть меню.
- Меню из трея: пауза, автозапуск при входе, выход.

## Как это работает

- `main.js` — фоновый процесс: трей, глобальный хук `uiohook-napi`, окна меню и тоста.
- Триггер срабатывает, когда **Shift зажат вместе с левой кнопкой мыши** — то есть именно во время перетаскивания. Одиночный Shift (например, при наборе текста) меню не открывает.
- `src/overlay.*` — радиальное меню (чистый CSS/JS, glass-эффекты, реакция на угол курсора).
- Перед показом меню `ffmpeg` (gdigrab) делает снимок области под ним (~0,2 с), а CSS размывает его внутри линзы. Поэтому стекло действительно матовое: фон под меню виден, но размыт, а снаружи остаётся резким.
  Снимок живёт только в памяти и никуда не сохраняется. Захват работает для основного монитора; на остальных меню показывает прозрачное стекло без размытия.
- `src/convert.js` — обёртка над `ffmpeg-static`: кодеки, прогресс, безопасные имена файлов.
- `src/toast.*` — стеклянный тост с прогрессом и результатом.
- `src/icon.js` — иконка приложения и трея рисуется кодом (PNG-энкодер без зависимостей).

## Настройки

Хранятся в `%APPDATA%/glass-convert/settings.json`:

```json
{
  "enabled": true,
  "autoLaunch": false
}
```

Менять можно и через меню в трее.

## Сборка portable .exe (по желанию)

```bash
npm i -D electron-builder
npx electron-builder --win portable
```

Готовый файл появится в `dist/`.

## Превью интерфейса

```bash
npm run preview
```

Скриншоты складываются в `preview/`.

## Проверка конвертера

```bash
node scripts/test-convert.js
```

Скрипт генерирует тестовые файлы и прогоняет все основные форматы.
